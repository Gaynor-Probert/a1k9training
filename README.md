# a1k9training.co.uk

The site of Gaynor Probert, dog behaviourist and trainer in South Wales.
A static site generated by [kiss-ssg](https://www.npmjs.com/package/kiss-ssg)
(Handlebars views, markdown partials) and styled with Tailwind CSS v4.

## Install

```bash
npm install
```

Node ≥ 22.12 (see `engines`).

## Build

```bash
npm run build       # compile the stylesheet, then generate the site into docs/
```

`npm run build` is the single command Netlify runs; the publish directory is
`docs/`. It is `npm run css` followed by `node generate`.

| Script | What it does |
| ------ | ------------ |
| `npm run build` | `css` then `gen` — the production build |
| `npm run css` | Tailwind: `src/styles/site.css` → `src/assets/css/site.css`, minified |
| `npm run css:watch` | the same, rebuilding on every save |
| `npm run gen` | kiss only: build `docs/` from `src/` |
| `npm run dev` | kiss dev server with live reload — it prints the URL it took |

**While developing, run two terminals**: `npm run css:watch` in one and
`npm run dev` in the other. kiss copies `src/assets/` into the build, so a
Tailwind rebuild lands in `src/assets/css/site.css`, kiss's watcher sees the
change and reloads the browser. A kiss asset-pipeline hook
(`config.assets.pipeline`) will fold the Tailwind watcher into `npm run dev`
shortly, and this note goes away with it.

## Layout

```
src/pages/          one .hbs per page — the URL structure
src/layouts/        layout.hbs (model-driven hero) and layout-video.hbs (home)
src/partials/       markdown and .hbs fragments; layout/ holds the shell
src/models/         page data as JSON
src/controllers/    per-page data reshaping
src/styles/site.css Tailwind entry: @theme tokens + the shared component classes
src/assets/         copied verbatim into the build (images, fonts, js, css)
docs/               build output — never edited by hand, emptied on every build
qa/                 Playwright and Lighthouse harness
planning/           migration plan and session notes
```

`src/assets/css/site.css` is **generated** and gitignored. Edit
`src/styles/site.css` instead.

## Design system

Tokens live in the `@theme` block of `src/styles/site.css`: a deep green brand
ramp, a warm sand ground, a dark-slate ink ramp for text, and an amber accent
reserved for calls to action. Headings are self-hosted Buenard 700
(`src/assets/fonts/buenard-700.woff2`, preloaded); body copy is the system sans
stack. Every text/background pair in the shell clears WCAG AA.

Templates should reach for Tailwind utilities. The small set of component
classes in `@layer components` — `.btn` (with `.btn-primary`, `.btn-secondary`,
`.btn-accent`, `.btn-sm`, `.btn-lg`), `.card`, `.callout`, `.page-header`,
`.figure-left` / `.figure-right`, `.badge`, `.prose-site` — exists for the
markdown and raw-HTML partials, which cannot carry a dozen utilities per
element. Each one is commented in `src/styles/site.css`.

## Cache busting

`generate.js` sets `assets: { hash: true }`, so every emitted `.css`/`.js` is
renamed to carry a hash of its bytes. Templates always ask for the plain name
through kiss's `{{asset}}` helper (`href="/{{asset "css/site.css"}}"`) and the
config decides the caching policy.

## Deploy

Netlify builds on push. Build command `npm run build`, publish directory
`docs/`. Netlify must install devDependencies (Tailwind's CLI is one) and run
Node ≥ 22.12.
